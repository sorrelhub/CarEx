## Features

### Speed
- Configurable boost amount (0-1000)
- Smooth start with adjustable acceleration rate
- Easy Steer (improved steering at high speeds)
- Preserve Gravity (prevents flying off bumps)
- Inertia Multiplier (physics-based velocity boost)

### Fly
- Car fly with adjustable speed (0-1000)
- Noclip mode (fly through walls)

### Physics
- Vehicle Jump with adjustable power
- Bounce Mode (rubber car effect)

### Air Control
- Keyboard rotation (pitch, yaw, roll)
- Configurable rotation speed

### Safety
- Speed Limiter (anti-ban, caps max speed)

### Other
- Full keybind customization
- Config save/load system
- WindUI interface
